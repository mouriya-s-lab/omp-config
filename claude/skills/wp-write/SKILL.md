# 写作

## 这个阶段解决什么问题

大纲给出了逻辑骨架（论点、论据、结构、节奏），但骨架不是文章。这个阶段把骨架转化为连贯的、有体裁定位的文本。

输入：素材 + `outline.md` + 可选风格 skill
产出：`draft.md`

## 约束

- 不改大纲骨架。如果写着发现大纲有问题，回阶段二改
- 素材处理：字幕保留推理过程和原话、技术文档保留关键细节、案例集找主线不逐条搬运

---

## 第一步：定位

在开始写作之前，必须在以下维度上确定这篇文章的定位。如果加载了风格 skill，用风格 skill 的取值覆盖默认值。

### 维度 1：交际目的

这篇文章要完成什么社会功能？

**默认值**：向读者传达一组经过组织的信息和分析。
**风格 skill 覆盖示例**：博客 = 分享个人思考并引发讨论；报告 = 提供证据支持的分析以辅助决策。

### 维度 2：语步结构

文章必须经过哪些功能阶段？哪些是必要的，哪些是可选的？

**默认值**：引入 → 展开 → 收束。具体语步由大纲的结构选择决定。
**风格 skill 覆盖示例**：博客 = Hook → Position → Support → Engagement；报告 = Background → Findings → Analysis → Conclusions → Recommendations。

### 维度 3：语场 (Field)

专业程度和术语密度。

**默认值**：跟随大纲中读者画像的知识边界定义。边界内的术语直接用，边界外的关键术语首次出现时给一句话定义。
**风格 skill 通常不覆盖此维度**——由读者画像决定。

### 维度 4：语旨 (Tenor)

作者和读者之间的关系。三个子维度：

- **权力关系**：平等 / 专家对读者 / 机构对个人
- **情感距离**：高情感介入 / 中性 / 低情感介入
- **社会距离**：近（持续关系）/ 远（单次交际）

**默认值**：专家对读者、中性情感、中等社会距离。
**风格 skill 覆盖示例**：博客 = 近平等、高情感、近距离；报告 = 专家对决策者、低情感、远距离。

**Tenor 的语言后果**（定位确定后，按这些规则执行）：

| Tenor 定位 | 人称 | 情态词 | 态度表达 |
|-----------|------|--------|---------|
| 近距离/高情感 | 第一、二人称 | 认识情态（我觉得、可能、也许） | 情感和判断丰富 |
| 远距离/低情感 | 第三人称/被动 | 义务情态（应当、必须、建议） | 以鉴赏为主，克制情感 |

### 维度 5：语式 (Mode)

在口语-书面连续体上的定位。

**默认值**：书面为主，允许适度口语化表达。
**风格 skill 覆盖示例**：博客 = 书面化的口语（written-as-if-spoken）；报告 = 极度书面化。

**Mode 的语言后果**：

| Mode 定位 | 连接词 | 句法 | 词汇 |
|----------|--------|------|------|
| 偏口语 | 所以、但是、而且 | 短句为主，并列多于嵌套 | 日常词汇优先 |
| 极书面 | 因此、然而、此外 | 复杂从句，嵌入式结构 | 专业术语、名词化 |

### 维度 6：评价姿态

用什么方式表达立场和态度。

- **态度类型**：情感（affect，表达感受）/ 判断（judgement，评价行为）/ 鉴赏（appreciation，评价事物）
- **声音模式**：单声（monogloss，呈现为不容置疑的事实）/ 多声（heterogloss，承认其他可能性）

**默认值**：以鉴赏为主，多声。
**风格 skill 覆盖示例**：博客 = 情感+判断丰富，多声（"我觉得""也许""但我不确定"）；报告 = 鉴赏为主，倾向单声但用制度化的 hedging（"数据表明""证据显示"）。

### 维度 7：信息密度

每个句子承载多少信息量。

**默认值**：中等密度，跟随大纲的节奏标注（慢镜头段落降密度展开细节，快进段落提密度）。
**风格 skill 覆盖示例**：博客 = 中低密度（留呼吸感，展开类比和场景）；报告 = 中高密度（读者预期密集分析）。

---

写作前，在 `draft.md` 的开头（写完后删除）写下每个维度的定位值，确认自己知道要写什么样的文本。格式：

## 第二步：翻译

定位确定后，按以下关键动作将大纲转化为文本。

### 关键动作 1：段落展开

**做什么**：把大纲中每个段落条目展开为完整的段落。

**操作**：对大纲中的每个段落条目：
1. 看节奏标注：慢镜头 / 快进 / 金币
2. 按标注决定展开策略：
   - **慢镜头**：完整展开。给出论据的全部细节，还原场景，展示推理过程。一个慢镜头段落通常 150-300 字
   - **快进**：一两句话完成过渡。只传递必要的连接信息。通常 30-80 字
   - **金币**：在段落中嵌入一个具体的、意外的、有画面感的细节。可以是数字、引用原话、反直觉的事实、生动的类比
3. 看论据标注：数据 / 案例 / 引用 / 推理 / 类比
4. 从素材中提取对应的论据材料，嵌入段落

**做到什么程度**：每个段落的展开密度与节奏标注一致。不是每个段落都要"充分展开"——快进段落就该短。

### 关键动作 2：段落衔接

**做什么**：确保段落之间的过渡自然，读者不会感到跳跃。

**操作**：写完第 N 段后，检查第 N+1 段的开头：
1. 大纲中的追问链说读者此时会问什么？
2. 第 N+1 段的第一句话是否在回应这个追问？
3. 如果不是，需要一句桥接句

**衔接方式取决于 Mode 定位**：
- 偏口语 Mode：自然过渡，可以用"但问题是""所以""不过"
- 极书面 Mode：逻辑连接词，"然而""基于上述分析""在此基础上"

**做到什么程度**：逐对检查所有相邻段落的衔接。

### 关键动作 3：素材融合

**做什么**：把素材中的内容融入文本，而不是搬运。

**操作规则**：
- **引用原话**：保留说话人的语气和措辞，不改写成书面体。用引号标注
- **数据和数字**：保持精确，不四舍五入（除非原始数据就是模糊的）
- **推理过程**：如果素材中有一段推理链，保留推理的关键步骤，不要只给结论
- **多源素材**：不同来源的信息按逻辑关系组织（因果、对比、互补），不按文档顺序或时间线排列

**Tenor 对素材融合的影响**：
- 近距离 Tenor：可以评论素材（"这个数字让人吃惊"），可以表达对素材的个人解读
- 远距离 Tenor：区分事实和推断，事实直接陈述，推断用 hedging 标注（"这表明""可能意味着"）

### 关键动作 4：信息密度校准

**做什么**：检查每个段落的信息密度是否与定位和节奏标注匹配。

**密度过高的信号**：
- 一个段落里塞了三个以上独立论点
- 读者需要反复读才能理解
- 没有任何具体细节（全是抽象概括）

**密度过低的信号**：
- 同一个意思用不同说法重复了两遍以上
- 段落中有大量"装饰性"形容词但不传递新信息
- 过渡段超过三句话

**校准方式**：
- 密度过高 → 拆分段落，或把抽象概括替换为具体案例（案例占空间但更容易理解）
- 密度过低 → 删除重复，压缩过渡

### 关键动作 5：体裁一致性自检

**做什么**：写完全文后，通读一遍，检查是否在所有维度上保持了定位的一致性。

**检查项**：
- [ ] 人称使用是否全文一致（没有一段用"我"一段用被动语态）
- [ ] 情态词选择是否一致（没有一处说"我觉得"一处说"证据表明"）
- [ ] 连接词风格是否一致（没有一段用"所以"一段用"因此"）
- [ ] 信息密度是否跟随节奏标注（慢镜头段落确实比快进段落长）
- [ ] 语步结构是否完整（定位中列出的必要语步都出现了）

如果发现不一致，统一为定位值。

删除开头的定位注释后保存。draft.md 是写作阶段的最终产出，交给润色阶段。
