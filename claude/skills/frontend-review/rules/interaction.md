# Interaction Consistency — MEDIUM

Same patterns should produce same behaviors everywhere.

## interaction-mixed-click
Same-looking elements do different things on click. Find all instances of same UI pattern across views, click each, compare behavior.

## interaction-inconsistent-crud
Create/edit/delete patterns differ across entity types. One uses dialog, another uses page, another uses inline — three paradigms for the same operation.

## interaction-mode-confusion
Implicit modes change how interactions work. Same button/key does different things depending on invisible state.

## interaction-inconsistent-keyboard
Keyboard shortcuts work on some pages but not others. Escape closes modals on one page, doesn't on another.
