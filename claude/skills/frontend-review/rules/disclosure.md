Show what's needed now. Complexity available but not mandatory. Essentials never hidden.

Too many fields for the simple case. Count fields visible before scrolling. Are all needed for the basic path?

## disclosure-hidden-essential

## disclosure-state-dependent
Controls appear/disappear based on state, but state isn't obvious. Missing element not explained.

## disclosure-overload
Single view shows everything at once. Too many distinct items to process without scrolling or context-switching.
