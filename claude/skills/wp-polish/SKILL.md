# 润色

## 这个阶段解决什么问题

初稿的结构和论证已经定好了，这个阶段处理表达层面的问题。分两轮执行，每轮有制动机制防止过度修改。

输入：`draft.md` + `outline.md`（对照用）
产出：`article.md`

## 约束

不改结构。如果发现结构性问题（逻辑线断裂、论点缺失、结构不匹配），回阶段二或三修，不在润色阶段打补丁。

---

## 第零步：提取全局目标

在开始任何修改之前，从 `outline.md` 中提取 3-5 条全局目标。这些目标是后续所有修改的唯一理由——没有对应目标的改动不做。

**提取方法**：
1. 读 `outline.md` 中的核心论点 → 目标："核心论点的清晰度和说服力"
2. 读读者画像中的预期收获 → 目标："读者能获得 ___"
3. 读追问链 → 目标："追问链的连贯性"
4. 读节奏标注 → 目标："信息密度与节奏标注的匹配度"
5. 如果加载了风格 skill，读其"对润色阶段的额外检查" → 追加为目标

**产出格式**：

```
全局目标：
1. ___
2. ___
3. ___
（每个目标一句话，可验证）
```

---

## 第一轮：Surface Changes

只做不改变意义的修改。这一轮的目的是清理表达，不是重新思考内容。

### 允许的操作

- 语法和标点修正
- 词汇替换（同义替换，不改变语义）
- 句子合并或拆分（不改变信息内容）
- 删除冗余词（"进行分析" → "分析"）
- 调整句式节奏（打破连续相同句式）

### 禁止的操作

- 添加新信息
- 删除论据或论点
- 改变段落顺序
- 改变论证方向

### 检查项

**AI 写作痕迹**：
- 空洞形容词（"至关重要""深远影响""全面覆盖"）→ 替换为具体描述或删掉
- 三段式排比 → 改成两项或四项，或者打散
- 设问句堆砌（"那么...呢？""这意味着什么呢？"）→ 直接陈述
- 套话连接词（"此外""值得注意的是""不可否认"）→ 删掉或用逻辑关系替代
- 否定式排比（"不是X而是Y""不仅仅是...更是..."）→ 直接说Y
- 过度平衡（"一方面...另一方面..."）→ 如果有明确立场就直接说

**句式节奏**：
- 连续五句以上相同句式结构？→ 变换长短句
- 段落间信息密度是否均匀化？→ 有的段落该密（论证段），有的该疏（过渡段）
- 连续多段相同长度？→ 有意识地制造长短段交替

**中文语感**：
- "的"字堆叠（"AI 的快速发展的背景下的行业的变化"）→ 拆分或重组
- "进行 XX"式名词化（"进行分析""进行讨论"）→ 直接用动词
- 翻译腔（"在...方面""基于...的考虑""关于...的问题"）→ 改成自然中文

### 第一轮制动

完成 surface changes 后，逐段对比 `draft.md` 和修改后的版本：
- 每个改动是否服务于全局目标中的至少一条？标注对应的目标编号
- 改后的段落是否确实比改前更好？如果不确定，**保留原文**
- 是否有改动意外改变了原文的语义？如果有，撤回

产出：`draft-surface.md`（第一轮结果，内部中间文件）

---

## 第二轮：Text-Based Changes

在全局目标指导下做改变局部意义的修改。这一轮处理 surface changes 解决不了的问题。

### 允许的操作（每个都必须标注服务于哪条全局目标）

- 补充缺失的桥接句（服务于追问链连贯性）
- 补充或替换不够有力的论据细节（服务于核心论点说服力）
- 调整术语解释（服务于读者预期收获）
- 补充首次出现的概念定义（服务于读者预期收获）

### 禁止的操作

- 添加大纲中没有的新论点
- 删除整个段落
- 改变段落顺序
- 改变核心论点

### 检查项

**逻辑衔接**：
逐段检查。读完第 N 段，遮住第 N+1 段，问："读者读到这里脑中会冒出什么问题？"然后看第 N+1 段开头是否回应了那个问题。
- 自然衔接 → 不改
- 需要桥接 → 加一句桥接句，标注服务于哪条全局目标
- 逻辑断裂 → 这是结构问题，回阶段二，不在这里修

**承诺兑现**：
列出所有承诺（标题暗示、开头段提出的问题、小标题暗示、行文中的预告），逐个确认兑现。未兑现的要么补上，要么改掉承诺。

**细节充分性**：
找到最重要的 2-3 个判断。对每个判断：
- 删掉论点只留论据，论据本身能让读者推出论点吗？
- 论据类型够多样吗？
- 具体的数字、人名、场景、原话保留了吗？

**读者知识门槛**：
从 `outline.md` 取出读者知识边界，扫描文章中所有专业术语：
- 在边界内 → 不解释
- 在边界外但关键 → 首次出现加一句话定义
- 在边界外且非关键 → 删掉或替换

### 第二轮制动

完成 text-based changes 后，执行与第一轮相同的对比检查，但对比对象是 `draft-surface.md`：
- 每个改动标注服务于哪条全局目标
- 改后是否确实比改前更好？不确定则**保留原文**
- 特别检查：补充的内容是否引入了新的 AI 写作痕迹？如果有，在不改变语义的前提下修正措辞

---

## 最终检查

两轮都完成后，通读全文做最终确认：

1. **与 draft.md 的整体对比**：article 整体上是否比 draft 更好？如果 draft 的某些段落表达更有力、更自然，还原那些段落
2. **全局目标核验**：逐条检查全局目标，每条目标在 article 中是否比在 draft 中实现得更好？
3. **风格 skill 额外检查**：如果加载了风格 skill，执行其"对润色阶段的额外检查"

如果最终检查发现 article 整体上不如 draft，说明改动方向有误。此时应该从 `draft.md` 重新开始第一轮，而不是在错误的基础上继续修补。

---

## 产出：`article.md`

最终文章。删除所有内部标注（全局目标、改动对应关系等）后保存。`draft-surface.md` 是内部中间文件，不需要保留在最终输出目录中。
